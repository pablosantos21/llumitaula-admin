# Domain docs

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions in `docs/adr/` when that directory exists.
- If `CONTEXT-MAP.md` exists, follow it and read the context docs relevant to the task.

If these files do not exist, proceed without creating them upfront. Use the domain vocabulary found in the relevant code and docs; flag terminology or decisions that need clarification.

## Layout

This is a single-context repo: domain context belongs in a root `CONTEXT.md`, with architectural decisions in `docs/adr/` when needed.
